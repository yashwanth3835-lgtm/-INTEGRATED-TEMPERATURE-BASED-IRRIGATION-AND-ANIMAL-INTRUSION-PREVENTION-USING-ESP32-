# 🌱 Integrated Temperature-Based Irrigation and Animal Intrusion Prevention Using ESP32

## 📌 Project Overview

This project is an IoT-based smart farming system designed to automate irrigation and protect agricultural fields from animal intrusion.

The system monitors temperature and soil conditions and automatically controls the water pump when irrigation is required. It also detects the presence of animals in the field and provides an alert to help prevent crop damage.

## 🎯 Objectives

- Automate the irrigation process.
- Monitor environmental conditions.
- Reduce unnecessary water usage.
- Detect animal intrusion in agricultural fields.
- Provide alerts during animal intrusion.
- Reduce manual effort for farmers.

## 🔧 Technologies Used

- ESP32
- Temperature Sensor
- Soil Moisture Sensor
- Animal/PIR Sensor
- Water Pump
- Relay Module
- Buzzer
- IoT Technology
- Arduino IDE

## ⚙️ Working Principle

1. The sensors continuously monitor the field conditions.
2. The temperature and soil moisture conditions are checked by the ESP32.
3. When the soil becomes dry, the ESP32 activates the water pump through the relay.
4. When sufficient moisture is detected, the pump is automatically switched OFF.
5. The animal detection sensor monitors the field for intrusion.
6. When an animal is detected, the system activates an alert using a buzzer.
7. Thus, the system provides automatic irrigation and animal intrusion prevention.

## 🏗️ System Components

| Component | Function |
|-----------|----------|
| ESP32 | Main controller |
| Temperature Sensor | Measures temperature |
| Soil Moisture Sensor | Detects soil moisture |
| PIR/Animal Sensor | Detects animal movement |
| Relay Module | Controls the water pump |
| Water Pump | Provides irrigation |
| Buzzer | Gives intrusion alert |
